# Readiness probe

Run `npm install` and `npm test` in this directory. The Vitest tests exercise the enabled and disabled paths of the readiness probe.

With the BehavProof CLI installed, run `behavproof test` to generate native test evidence. Before running in protected CI, enroll the reviewed project configuration on an independent host. See the [Protected Quality CI guide](../../docs/quality-ci.ja.md) for the host setup.
